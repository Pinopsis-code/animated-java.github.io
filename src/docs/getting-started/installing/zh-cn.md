# 安装 Animated Java

## 你需要的软件

-   [Blockbench](https://blockbench.net/) 5.1.4 或更高版本。
-   [Minecraft: Java Edition](https://www.minecraft.net/en-us/download) 1.20.4 或更高版本。

## 从插件管理器中获取

1. 启动 Blockbench 并找到 **文件 <i class="minecraft-right-arrow"></i> 插件…** 打开插件管理器。

    ![在 Blockbench 打开插件管理器](/images/docs/getting-started/installing/step1.png)

2. 搜索 "Animated Java"。

    ![在插件管理器搜索 Animated Java](/images/docs/getting-started/installing/step2.png)

3. 点击 **安装**。

## 从 URL 中获取

直接从 GitHub 安装最新发布版本：

1. 打开插件管理器（**文件 <i class="minecraft-right-arrow"></i> 插件…**）。
2. 点击 **从 URL 加载插件**。
3. 粘贴这个 URL：

    ```
    https://github.com/Animated-Java/animated-java/releases/latest/download/animated_java.js
    ```

## 从文件获取

如果你下载了 `animated_java.js`：

1. 打开插件管理器（**文件 <i class="minecraft-right-arrow"></i> 插件…**）。
2. 点击 **从文件加载插件**。
3. 选择下载的 `animated_java.js` 文件。

:::warning[不兼容的插件]
有些 BlockBench 插件与 Animated Java 不兼容。如果你加载了这类插件，Animated Java 将弹出窗口列出它们，并提供禁用它们的按钮。
:::
