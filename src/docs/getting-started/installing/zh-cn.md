# 安装 Animated Java

## 你需要

-   [Blockbench](https://blockbench.net/) 5.1.4 或更高版本。
-   [Minecraft: Java Edition](https://www.minecraft.net/en-us/download) 1.20.4 或更高版本。

## 在插件

1. Open Blockbench and go to **File <i class="minecraft-right-arrow"></i> Plugins...** to open the Plugin Manager.

    ![Open the plugin manager in Blockbench](/images/docs/getting-started/installing/step1.png)

2. Search for "Animated Java".

    ![Search for Animated Java in the plugin marketplace](/images/docs/getting-started/installing/step2.png)

3. Click **Install**.

## From a URL

To install straight from the latest GitHub release:

1. Open the Plugin Manager (**File <i class="minecraft-right-arrow"></i> Plugins...**).
2. Click **Load Plugin from URL**.
3. Paste this URL:

    ```
    https://github.com/Animated-Java/animated-java/releases/latest/download/animated_java.js
    ```

## From a File

If you've downloaded `animated_java.js` yourself:

1. Open the Plugin Manager (**File <i class="minecraft-right-arrow"></i> Plugins...**).
2. Click **Load Plugin from File**.
3. Select the downloaded `animated_java.js` file.

:::warning[Incompatible plugins]
Some Blockbench plugins are known to break Animated Java. If you have one installed, Animated Java shows a popup listing them, with buttons to disable them.
:::
